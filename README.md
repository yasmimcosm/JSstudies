## 📖 Sobre o Repositório

Este repositório foi criado com o objetivo de **centralizar e organizar meus estudos em JavaScript**, servindo como um espaço para armazenar códigos de prática, exercícios, exemplos e pequenos experimentos.

Ele funciona como um **diário de aprendizado**, mostrando minha evolução no JavaScript — desde conceitos básicos até funcionalidades mais avançadas.

---

## 🎯 Objetivos

* Consolidar fundamentos do **JavaScript**
* Praticar lógica de programação
* Aprender manipulação do **DOM**
* Trabalhar com eventos e interações
* Criar pequenos scripts e mini-projetos
* Manter um histórico organizado de aprendizado

---

## ✨ Conteúdos Abordados

* Variáveis (`var`, `let`, `const`)
* Tipos de dados
* Operadores
* Estruturas condicionais
* Laços de repetição
* Funções
* Manipulação do DOM
* Eventos
* Arrays e objetos
* Métodos comuns (`map`, `filter`, `forEach`, etc.)

---

## 🛠️ Tecnologias Utilizadas

* **JavaScript (ES6+)**
* **HTML5** (quando necessário para testes)
* **CSS3** (para visualização básica)
* **Git & GitHub**
* **VS Code**
